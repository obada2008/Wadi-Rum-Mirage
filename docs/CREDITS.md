# Credits and external resources

Wadi Rum Mirage is maintained by **Obada Khader**. The original project UI and analysis source are included in this repository. Third-party content and infrastructure keep their own attribution and terms.

## Heritage and mapping

- Wadi Rum Protected Area heritage reference: [UNESCO World Heritage Centre](https://whc.unesco.org/en/list/1377).
- Heritage reference: [Department of Antiquities of Jordan](https://www.doa.gov.jo/EN/ListDetails/World_Heritage_Sites_in_Jordan/1158/7).
- Map content: [OpenStreetMap contributors](https://www.openstreetmap.org/copyright). Some embeds and externally hosted images require internet access and can share normal network metadata with the third-party providers.
