# Limitations and research honesty

This first release implements deterministic heuristic rules, not machine learning. Its score is not a fraud probability. A trust-transfer edge is inferred from the co-occurrence of institutional language, sensitive requests, and connection cues (or URL presence), so the logic is susceptible to false positives and false negatives. It cannot fact-check claims.

Novelty of this implementation has not been established; evidence-to-action validation overlaps with existing work on argument mining, misinformation and social engineering detection. Do not claim to be the first or best without peer-reviewed comparison and independent evaluation.
